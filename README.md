# git-practice
## 概要
GitとGitHubの基本的な使い方を練習するためのリポジトリです。
コマンド操作を通じて、ファイルの変更やリポジトリへのアップロード(push)の手順で学んでいます。
##使い方
１，リポジトリをクローンまたはローカルに作成します。
２，ファイルの追加や編集を行い、'git add'と'git commit'で記録します。
cat << 'EOF' > README.md
# git-practice
## 概要
GitとGitHubの基本的な使い方を練習するためのリポジトリです。
コマンド操作を通じて、ファイルの変更やリポジトリへのアップロード(push)の手順で学んでいます。
##使い方
１，リポジトリをクローンまたはローカルに作成します。
２，ファイルの追加や編集を行い、'git add'と'git commit'で記録します。
３，'git push'を実行して、変更内容を GitHub に反映させます。
